# characters-remove-import

Размер: S

## Контекст

Владелец продукта передумал насчёт функции «Импорт» персонажа из текста — она полностью убирается.
Новая концепция (на будущее, НЕ часть этой карточки — данных для неё ещё нет): пул заранее созданных
персонажей («прегенов»), которые владелец продукта загрузит позже как готовые листы персонажей;
вместо кнопки «Импорт» появится кнопка вроде «Выбрать готового персонажа», открывающая список уже
перенесённых в приложение персонажей без какого-либо парсинга текста. Эта кнопка/список — отдельная
будущая карточка, когда появятся реальные данные персонажей; в этой карточке она не создаётся.

`ImportPage.tsx` не дергает никаких Tauri-команд (`invoke`) — это чисто фронтенд-парсинг вставленного
текста, значит удаление ограничивается фронтендом, бэкенд не трогать.

Точки, где «Импорт» подключён (`CharactersPage.tsx`):
- `import { ImportPage } from "./ImportPage";` (строка 7)
- `type Panel = "none" | "import" | "wizard";` (строка 10) — вариант `"import"` убрать
- Кнопка «Импорт» (строки 222-228)
- Условный рендер `{panel === "import" && <ImportPage />}` (строка 237)

## Что нужно

1. Удалить кнопку «Импорт» и связанный с ней рендер из `CharactersPage.tsx`, убрать `"import"` из
   типа `Panel`, убрать импорт `ImportPage`.
2. Удалить файлы `src/ui/pages/ImportPage.tsx`, `src/ui/pages/ImportPage.test.tsx`,
   `src/ui/pages/ImportPage.css` целиком — код полностью выводится из кодовой базы, не оставлять
   мёртвым.
3. Проверить, что больше нигде в кодовой базе (`grep -r ImportPage`) нет ссылок на удалённые файлы
   (например, в `App.tsx`, если там есть прямая ссылка на маршрут импорта — проверить и убрать, если
   найдётся).
4. Не создавать кнопку/логику «Выбрать готового персонажа» — это отдельная будущая карточка, ждущая
   реальных данных персонажей от владельца продукта.

## DoD

- Кнопки «Импорт» нет нигде в интерфейсе персонажей.
- Файлы `ImportPage.*` удалены из репозитория, нет ни одной оставшейся ссылки на них.
- `$GATES_CMD` зелёный (включая обновление/удаление любых тестов, которые ссылались на `ImportPage`).

## Критерии приёмки

- На странице «Персонажи» видна только кнопка «Создать персонажа по правилам» — кнопки «Импорт» нет.
- В репозитории нет файлов `ImportPage.tsx`/`.test.tsx`/`.css`.
