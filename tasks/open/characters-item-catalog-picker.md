# characters-item-catalog-picker

Размер: M

## Контекст

В карточке персонажа (`CharactersPage.tsx`, блок «Инвентарь», ~строка 102-131) добавление предмета —
свободный текстовый `<input placeholder="Новый предмет">` + кнопка «Добавить» (`addItem`,
~строка 39-47). Владелец продукта хочет выпадающий список с готовыми предметами при сохранении
возможности ввести своё название — по образцу уже существующего паттерна для поля «Состояние»
чуть ниже (~строка 147-158): `<input list="conditions-..."> + <datalist>`, который и подсказывает
варианты, и не мешает вписать что угодно вручную.

Уточнение владельца продукта: список должен быть **полным каталогом** известных приложению
предметов — не только «снаряжение авантюриста».

Сейчас в `characterCreationData.ts` есть отдельные типизированные списки: `WEAPONS` (~481),
`INSTRUMENTS` (~558), `ADVENTURING_GEAR` (~613), `DWARF_TOOL_CHOICES` (~982), `ARTISAN_TOOLS`
(~994) — у каждого есть поле `name`. **Доспехов как отдельного списка нет** — только имена доспехов,
встречающиеся строками внутри `CLASS_EQUIPMENT` (например «Кожаный доспех», «Кольчуга», «Чешуйчатый
доспех»). SRD-данные по доспехам есть в `src-tauri/rules/rules.json` → секция `equipment-armor`
(таблица «Доспехи» с колонками имя/цена/КД/вес и т.п.), тем же способом, каким уже раньше вручную
сверялись `WEAPONS`/`ADVENTURING_GEAR` с rules.json (см. комментарий в начале
`characterCreationData.ts`: «сверены вручную с текстом в rules.json... автопарсинг такого
ненадёжен»).

## Что нужно

1. Добавить в `characterCreationData.ts` список `ARMOR: GearData[]` (тот же тип, что уже
   используется у `ADVENTURING_GEAR`, поля `name`/`cost`/`weight`), заполненный вручную по таблице
   «Доспехи» из `rules.json → equipment-armor` (лёгкие/средние/тяжёлые доспехи + щит) — не выдумывать
   цифры, сверить с таблицей.
2. Добавить объединённый список имён предметов для подсказок инвентаря, например
   `export const ALL_ITEM_NAMES: string[]` — имена из `WEAPONS`, `ARMOR` (новый), `ADVENTURING_GEAR`,
   `INSTRUMENTS`, `ARTISAN_TOOLS`, `DWARF_TOOL_CHOICES` (объединить и убрать дубликаты по `name`).
3. В `CharactersPage.tsx`, блоке «Инвентарь» (~строка 121-130): заменить/дополнить `<input
   placeholder="Новый предмет">` тем же паттерном `list={...}` + `<datalist>`, что уже есть у поля
   «Состояние» (~147-158), с опциями из `ALL_ITEM_NAMES`. Игрок как и раньше может ввести любое
   произвольное название — `datalist` только подсказывает, не ограничивает.

## DoD

- Поле добавления предмета показывает выпадающие подсказки из полного каталога (оружие, доспехи,
  снаряжение авантюриста, инструменты, музыкальные инструменты).
- Свободный ввод собственного названия предмета по-прежнему работает (как и раньше).
- `$GATES_CMD` зелёный.

## Критерии приёмки

- Открыть карточку персонажа, начать вводить в поле «Новый предмет» — видно выпадающие подсказки
  из разных категорий (например, ввести «Кин» — подсказка «Кинжал» из `WEAPONS`; ввести «Кож» —
  подсказка доспеха из нового `ARMOR`).
- Ввести полностью произвольное название, которого нет в каталоге, и нажать «Добавить» — предмет
  всё равно добавляется в инвентарь.

## Критерии тестирования

- Тест в `CharactersPage.test.tsx`, что `datalist` для инвентаря содержит опции хотя бы из
  нескольких категорий (например, один пример оружия и один пример доспеха).
