# Выбор ремесленного набора дварфа рисует горизонтальную прокрутку

## Адрес

Персонажи → Создать персонажа по правилам → Раса → Дварф → «Владение инструментами (на выбор)».

## Наблюдение

При окне 1018×797 поле выбора занимает примерно 315 px, но внутри него появляется отдельная горизонтальная полоса прокрутки. Одновременно горизонтальная прокрутка есть у всей области мастера: 2 горизонтальные полосы на одном экране вместо 0.

Из-за этого выбор из трёх коротких вариантов выглядит как обрезанный широкий документ, а не обычный список.

## Воспроизведение

1. Открыть мастер персонажа.
2. Выбрать «Дварф».
3. Прокрутить описание до выбора ремесленного набора.

## Ожидание

Список и колонка мастера помещаются по ширине окна без горизонтальной прокрутки; доступны инструменты кузнеца, пивовара и каменщика.
