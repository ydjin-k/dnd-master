# characters-background-language-choice

Размер: M

## Что нужно

По SRD 5.1 предыстории Дворянин (`noble`) и Мудрец (`sage`) дают на выбор ещё один язык (владелец
продукта подтвердил по памяти — сверить точную формулировку в купленной книге ownera, файл
`5e Dungeon and Dragons Книга игрока.pdf` в корне репозитория, уже в `.gitignore` — **не коммитить**,
использовать только чтобы подтвердить, у КАКИХ предысторий есть выбор языка и сколько именно, само
описание особенности предыстории не копировать/не переписывать оттуда, только список названий уже и
так стоит в `BACKGROUNDS`).

Сейчас язык можно выбрать только от расы (`RACE_LANGUAGES`, `chosenLanguage`, `finalLanguages` —
`CharacterWizard.tsx` ~строка 204-212). У предыстории такого механизма нет вообще.

Добавить аналогичный механизм для предыстории:

- Новая структура `BACKGROUND_LANGUAGES: Record<string, number>` (id предыстории → сколько языков
  на выбор даёт) в `characterCreationData.ts` — заполнить для всех предысторий, у которых по книге
  есть выбор языка (ожидается Дворянин и Мудрец, сверить оглавление/текст особенностей на выбор
  языка по книге — могут быть и другие, не гадать, смотреть факт).
- В мастере — если у выбранной предыстории `BACKGROUND_LANGUAGES[backgroundId] > 0`, показать
  дополнительный выбор языка(ов) на шаге предыстории (или на «Итоге», где сейчас уже есть выбор
  расового языка — тем же UI-паттерном), не пересекающийся с уже выбранными языками расы/явно
  выбранными ранее.
- `finalLanguages` включает языки от предыстории вместе с языками расы, без дублей.

## DoD

- Дворянин и Мудрец (и любая другая предыстория, у которой в книге действительно есть выбор языка)
  дают на «Итоге» выбор дополнительного языка(ов), результат попадает в `languages` готового
  персонажа.
- Предыстории без такой способности не показывают этот выбор вообще.

## Критерии тестирования

- Тест: выбрать предысторию Мудрец, выбрать язык — готовый персонаж содержит этот язык в
  `languages` (по аналогии с существующим тестом на языковой выбор расы).
- Тест: предыстория без выбора языка (например, Послушник) не показывает этот выбор.
