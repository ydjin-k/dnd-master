# ui-shell-players-window-commands-and-png-names

Зона: `ui-shell` (права окон Tauri) и `engine` (вкладка «Подземелья», выгрузка PNG). Размер: **S**.
Роль: Developer.

**Два хвоста после окна игроков (запись 213): окну игроков закрыть команды приложения, которые
ему не нужны, а у двух PNG-листов развести имена файлов по умолчанию.**

## Решения владельца (21.10.2026)

1. Права окна игроков закрыть строго — «да давай небольшую карточку».
2. Имена PNG-листов мастера и игроков по умолчанию разные — «Имена сохранить разные».
3. По окну игроков оставить как сделано: рамка поля по всему подземелью, имя и этаж в заголовке,
   «▼ вход» у открытой первой комнаты.

## Что уже есть

- `src-tauri/build.rs` — голый `tauri_build::build()`, без `AppManifest`. Поэтому все свои команды
  из `invoke_handler` в `lib.rs` (`save_campaign`, `delete_campaign`, `save_png_file`, бой и т. д.)
  доступны любому окну, включая `players`. В `capabilities/players.json` выданы только
  встроенные права (listen/unlisten, полный экран).
- Окну игроков нужна одна своя команда: `players_map_get`. `players_map_set` и
  `players_window_open` зовёт окно мастера.
- Имя файла: `pngFileName(name)` в `src/ui/dungeons/DungeonMapImage.tsx` даёт `<имя>.png`, его
  зовёт `DungeonsPage.tsx` (около `defaultPath`) для обоих листов.

## Что нужно

1. **Команды по окнам.** `build.rs` через `tauri_build::try_build` с
   `AppManifest::new().commands(&[...])` — все свои команды. Окну `main` в `default.json` выдать
   все, что ему нужны (по сути все), окну `players` в `players.json` — только `allow-players-map-get`.
   Проверить, что окно мастера ничего не потеряло: каждая команда из `invoke_handler` вызывается из
   `main` как раньше.
2. **Имена PNG.** Лист мастера — `<имя>.png`, лист игроков — `<имя> — для игроков.png` (подпись
   из `MAP_AUDIENCE_LABELS`, а не вторая строка). Прежняя замена недопустимых символов и запасное
   «подземелье» сохраняются для обоих.

## Чего НЕ делать

- Не менять поведение окна игроков и его вид.
- Не пушить, не сливать, `tasks/DONE.md` и карточку не трогать, `git add -A` не использовать.

## Пробы

- Имена: оба листа, имя с недопустимыми символами, пустое имя.
- Права: проба или разбор, что `players.json` не содержит ни одной команды записи, а `default.json`
  покрывает весь `invoke_handler` (перечень читается из `lib.rs`, а не переписан в пробу).
- **Живьём в окне Tauri:** окно мастера — создать/сменить/сохранить кампанию, бросок, бой,
  сохранить PNG; окно игроков открывается и получает схему; из окна игроков вызов
  `save_campaign` (через CDP) получает отказ. Своё окно по `--app pid:<свой>`, чужие
  `dnd-master.exe` не гасить.

- Два листа по умолчанию сохраняются под разными именами.
- `$GATES_CMD` зелёный, числа названы, основание замерено своей рукой до правок.
