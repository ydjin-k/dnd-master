# characters-healing-potions

Размер: S

## Контекст

Владелец продукта хочет несколько зелий лечения разного «размера» (малое/среднее/большое и т.д.) с
описанием, сколько костей кидать для лечения. `src-tauri/rules/rules.json` (перевод
longstoryshort.app) **не содержит раздела про магические предметы вообще** (проверено — нет ни
одной секции `magic-items*`/`potion*` в файле). Значит, как и в случае со `Spell`/`spells.json`
(см. `rules-spells-data`), текст и цифры нужно брать напрямую из официального SRD 5.1 PDF
(`media.wizards.com/2016/downloads/DND/SRD-OGL_V5.1.pdf`, CC BY 4.0 — открытая лицензия, уже
использовавшаяся для заклинаний) и переводить на русский самостоятельно — **не по памяти**: сверить
точный список тиров зелий лечения и их кости лечения по тексту PDF (раздел Magic Items → Potions),
не угадывать цифры.

## Что нужно

1. В `characterCreationData.ts` (или отдельном модуле рядом, на усмотрение исполнителя) добавить
   данные по зельям лечения — по факту найденным в PDF тирам (ожидается что-то в духе «Зелье
   лечения» / «Зелье большого лечения» / «Зелье превосходного лечения» и т.п. — точные названия и
   формулы лечения взять из текста PDF, не выдумывать), каждое с полями как минимум `name`,
   `healingDice` (например «2к4+2»), `description`.
2. Добавить эти зелья в общий каталог предметов (`ALL_ITEM_NAMES`/`ALL_ITEMS_WITH_COST`) — раз они
   могут лежать в инвентаре персонажа как обычный предмет.
3. Не проектировать отдельную «систему использования зелья» (авто-лечение при клике) — это не
   просили; зелье просто предмет в инвентаре с понятным описанием, лечение (какие кости кинуть)
   игрок применяет сам через существующую вкладку «Кубики» + ручную правку HP, как и всё остальное
   в приложении без систем отдыха/автоматизации.

## DoD

- В каталоге предметов есть несколько тиров зелий лечения с корректными (сверенными по
  официальному SRD PDF) формулами лечения в описании.
- `$GATES_CMD` зелёный.

## Критерии приёмки

- В поле «Новый предмет» инвентаря начать вводить «Зелье» — видно несколько тиров зелий лечения с
  указанием костей лечения в описании/подсказке.

## Критерии тестирования

- Тест, что данные по зельям присутствуют и попадают в объединённый каталог.
