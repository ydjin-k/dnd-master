# launcher-clock-face-redesign

Размер: L

Зона: `ui-shell`. Роль-исполнитель — `ui-developer` (см. `gamestudio/roles/ui-developer.md` и
`roles/_common.md`), не `developer`.

Фоновая картинка и трек уже присланы владельцем продукта и лежат в проекте (см. пункт 4 «Что нужно»).

## Контекст

Владелец продукта посмотрел уже встроенный лаунчер (вариант «Астральные врата» из
`section-theming-and-welcome`) и признал реализацию плохой:

1. **Баг**: текст (название кампании) вываливается за пределы круга — переполнение не обработано.
2. **Концептуальная проблема**: сам круг сейчас — просто декоративная рамка вокруг ОДНОЙ кампании
   («последняя кампания»), а остальные кампании живут отдельным плоским списком под ним
   (`.launcher__list`, «Другие хроники»). Владелец хочет, чтобы круг стал главной и единственной
   фичей для просмотра/выбора кампаний — принцип циферблата: стрелки-указатели на все кампании сразу
   по кругу, наведение подсвечивает имя, клик в центр раскрывает карточку выбранной кампании.

## Что нужно

### 1. Убрать переполнение текста

Название кампании не должно вылезать за пределы круга ни при каком разумном по длине имени —
перенос строки, уменьшение кегля под длину или обрезка с многоточием, на усмотрение исполнителя,
результат — текст всегда внутри окружности.

### 2. Циферблат вместо круга-рамки + списка

- Число стрелок-указателей = число сохранённых кампаний (не фиксировано 6) — **владелец
  подтвердил именно это**, а не жёсткий потолок в 6 позиций.
- **Обязательное условие**: имена кампаний по кругу не должны наезжать друг на друга ни при каком
  числе кампаний — при их росте плотность неизбежно растёт, значит нужен свой механизм
  (радиус круга, растущий с числом кампаний; минимальный угловой шаг между подписями с переносом на
  несколько колец; обрезка длинных имён; что угодно другое) — выбор конкретного механизма за
  исполнителем, наблюдаемый результат один: подписи не перекрываются, читаемы.
- Имена кампаний располагаются по кругу «в горизонтальной плоскости» (эффект наклонного циферблата/
  часов, лежащих плашмя, а не плоского фронтального круга) — как описал владелец продукта.
- Наведение мышкой на стрелку/точку кампании подсвечивает её название.
- Клик по кампании (или клик в центр после наведения — на усмотрение исполнителя, главное — понятный
  и однозначный жест) раскрывает панель с: названием кампании, числом героев, кнопкой «Продолжить»,
  кнопкой «Удалить». Логика этих трёх действий уже есть в `Launcher.tsx` (`continueCampaign`,
  `deleteCampaign`, счётчик `characterCount`) — переиспользовать, не переписывать.
- **Плоский список `.launcher__list`/«Другие хроники» убрать полностью** — круг теперь и есть
  единственный способ увидеть и выбрать любую сохранённую кампанию, второго места для этого в
  интерфейсе быть не должно (второй список — второй владелец того же факта, см. `roles/_common.md`).
- Убрать фразу **«Последняя кампания»** — не использовать её нигде взамен (владелец продукта прямо
  попросил это выражение убрать, не заменять другой формулировкой с тем же смыслом «главная/
  выделенная кампания»; сам циферблат ничего не выделяет как «последнее» — все кампании равноправны
  на круге, разница только в том, куда навёл/что раскрыл).

### 3. Форма создания новой кампании — остаётся отдельно, вне круга

Подтверждено владельцем: `.launcher__new` (поле имени + кнопка «Новая кампания») остаётся отдельным
блоком на экране, не встраивается в циферблат.

### 4. Фон и музыка

Оба файла от владельца продукта уже лежат в бандле, тем же способом, что и остальной аудио-контент
(`public/audio/`):

- **Картинка** — `public/images/launcher-background.png` — фон экрана лаунчера. Убедиться, что на
  тексте/цифeрблате остаётся читаемость (затемнение/градиент поверх, если требуется) — картинка
  тёмная и контрастная сама по себе, но проверить глазами.
- **Трек** — `public/audio/launcher-theme.mp3` — короткая фоновая музыка, зацикленная, пока открыт
  экран лаунчера. **В проекте пока нет инфраструктуры для зацикленной фоновой музыки**
  (`src/audio/uiSounds.ts` — только короткие одноразовые эффекты через Web Audio API) — эта карточка
  первая, кому она понадобится; обычный `<audio loop>`/зацикленный `HTMLAudioElement` подойдёт, не
  обязательно усложнять до отдельного модуля, если не появится второй потребитель.
- Музыка должна останавливаться при уходе с экрана лаунчера (кампания открыта) — не играть поверх
  игрового процесса.

## DoD

- Название кампании никогда не выходит за пределы круга.
- Циферблат показывает ВСЕ сохранённые кампании (число стрелок = число кампаний), имена не
  перекрываются при любом их количестве в разумных пределах (проверить хотя бы на 1, 3, 6, 12
  кампаниях).
- Плоского списка кампаний под кругом нет; фраза «Последняя кампания» нигде не встречается.
- Клик по кампании на круге открывает панель с названием/числом героев/«Продолжить»/«Удалить»,
  обе кнопки рабочие (используют существующие `continueCampaign`/`deleteCampaign`).
- Форма создания новой кампании работает как прежде, вне круга.
- Фон — присланная картинка; при открытии лаунчера играет присланный трек по кругу, останавливается
  при входе в кампанию.
- `$GATES_CMD` зелёный.

## Критерии приёмки

- Открыть лаунчер с 0 кампаний — видно пустое состояние (уже есть `launcher__portal--empty`, тоже без
  текста «последняя кампания», если он там есть).
- Создать 1 кампанию — на циферблате одна стрелка/точка, клик по ней раскрывает панель с верными
  данными.
- Довести число кампаний до 8-10 (вручную через `+ Новая кампания`) — все видны на круге, имена
  читаются, ни одно не наезжает на соседнее.
- Проверить длинное имя кампании (30+ символов) — не вылезает за круг ни в списке стрелок, ни в
  раскрытой панели.
- Открыть кампанию — фоновая музыка лаунчера перестаёт играть.

## Критерии тестирования

- `Launcher.test.tsx` перепишется под новую структуру (стрелка/панель вместо списка) — существующие
  три сценария (список кампаний и продолжение, создание, удаление с подтверждением) должны остаться
  проверены, просто через новые селекторы/жесты.
- Тест на непересечение подписей на большом числе кампаний, если для этого есть разумный
  программный критерий (например, вычисленные позиции не ближе X друг к другу) — если единственный
  надёжный способ проверить это визуально, так и написать в отчёте вместо выдуманной пробы.
