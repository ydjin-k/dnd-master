# characters-age-and-gold-limits

Размер: S

## Контекст

Владелец продукта протестировал мастера персонажа и нашёл два поля без видимого игроку предела:

1. Поле «Возраст» (`CharacterWizard.tsx`, ~строка 1205-1216, `age`/`setAge`) — обычный `<input
   type="number">` без `max` и без клампа в обработчике. Можно ввести любое число (проверено —
   «бесконечные числа»).
2. Поле «Золото» в блоке «Своя предыстория» (`CharacterWizard.tsx`, ~строка 925-938,
   `customBackground.gold`) — клампится корректно (`Math.min(30, ...)` в обработчике + `max={30}`
   на инпуте, это уже сделано в `characters-background-gold-cap-and-skill-bold`), но лимит нигде не
   написан явно текстом — игрок узнаёт о нём только наткнувшись на потолок.

## Что нужно

1. **Возраст**: добавить `max={500}` на инпут и клампить в обработчике тем же паттерном, что уже
   есть у золота — `Math.min(500, Number(raw) || 0)` (одного `max` на инпуте недостаточно, он не
   блокирует вставку/ввод значения программно, тот же урок уже учтён для золота). Рядом с полем
   (например, в `<label>` или через `placeholder`/маленькую подпись) явно написать предел, например
   «Возраст (до 500 лет)».
2. **Золото своей предыстории**: сама логика клампа уже верна, только добавить рядом с полем видимый
   текст предела, например «Золото (максимум 30 зм)» — по аналогии с тем, что нужно сделать для
   возраста.

## DoD

- Ввод/вставка значения больше 500 в поле «Возраст» приводит к сохранённому значению 500, не больше.
- Оба поля показывают предел текстом рядом с собой, видимым без необходимости сначала упереться в
  потолок.
- `$GATES_CMD` зелёный.

## Критерии приёмки

- В мастере персонажа ввести в «Возраст» число 99999 (вручную посимвольно или вставкой) — итоговое
  значение в персонаже не больше 500.
- Оба поля («Возраст», «Золото» в своей предыстории) визуально показывают свой предел рядом с собой.

## Критерии тестирования

- Тест в `CharacterWizard.test.tsx`: ввод возраста больше 500 (симуляция `fireEvent.change` с
  большим значением) даёт итоговое поле `age` не больше 500 у созданного персонажа.
