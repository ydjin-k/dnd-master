# characters-backgrounds-full

Размер: L

## Контекст

`BACKGROUNDS` в `src/ui/characterCreationData.ts` (~строка 263) сейчас содержит ровно одну
предысторию — Послушник, с комментарием «SRD 5.1 включает только одну предысторию целиком.
Остальные упомянуты в PHB, но не входят в открытый документ». Мастер персонажа (`CharacterWizard.tsx`,
~строка 711, `BACKGROUNDS.map(...)`) уже рендерит выбор карточкой из этого массива без какой-либо
специфичной для Послушника логики — добавление новых элементов в массив достаточно само по себе,
отдельной UI-работы не требуется.

Владелец продукта предоставил свою купленную книгу «5e Dungeon and Dragons Книга игрока» —
файл `5e Dungeon and Dragons Книга игрока.pdf` в корне репозитория. **Файл уже в `.gitignore`
(`/*.pdf`)** — не трогать это правило, не коммитить сам PDF ни при каких обстоятельствах.

## Источник и жёсткая граница — обязательно к прочтению

Это НЕ SRD-контент — покупка книги игроком не даёт приложению право распространять её текст. Уже
дважды в этом проекте явно отклонялось «переписать своими словами официальный текст как обход
лицензии» — пересказ не снимает защиту с производного произведения, когда он выполняет ту же
функцию, что оригинал.

Разрешено — то же самое, что уже сделано для `NAME_SUGGESTIONS` (см. комментарий над той константой):
**оригинальный контент, вдохновлённый общим духом жанра**, а не переписанный/пересказанный из книги.
Конкретно для каждой предыстории:

- **Название архетипа** взять из содержания раздела «Предыстории» в PDF (сами слова вроде «Солдат»,
  «Преступник», «Отшельник» — родовые обозначения профессии/архетипа, не творческое произведение) —
  это единственное, что можно напрямую взять из книги.
- **Всё остальное — владения навыками, список снаряжения, стартовое золото, особенность —
  придумать самостоятельно**, не подсматривая конкретную механическую сборку книги для этого
  архетипа. Не открывать страницу конкретной предыстории в PDF и не переносить её умения/снаряжение/
  золото/особенность даже в изменённом виде — работать от жанрового образа архетипа «в целом» (как
  большинство RPG вообще представляют себе солдата, преступника, отшельника), а не от конкретной
  реализации этой книги.
- Особенность (`feature`) — оригинальная механика/нарративная привилегия в стиле уже существующей
  особенности Послушника («Приют для верующих: ...») — свой текст, свой эффект, не совпадающий
  дословно или почти дословно с известной механикой книги.

Если после этого архетип выглядит неотличимо похожим на официальный (то же название + случайно тот
же смысл особенности) — это нормально для очень общих архетипов (например, у любого «Солдата» будет
что-то военное), тревога только если совпадает конкретная формулировка/цифры.

## Что нужно

1. Прочитать оглавление раздела «Предыстории» в PDF (только оглавление/список названий, не тексты
   самих предысторий) — получить точный список архетипов книги. Ожидается стандартный набор 5e
   (Послушник уже есть + порядка 12 других: Шарлатан, Преступник, Артист, Народный герой, Ремесленник
   гильдии, Отшельник, Дворянин, Чужеземец, Мудрец, Моряк, Солдат, Беспризорник — сверить с
   реальным оглавлением книги, точный список и порядок может отличаться).
2. Для каждого архетипа из списка (кроме уже существующего Послушника) — новый элемент `BackgroundData`
   в `BACKGROUNDS`: `id` (kebab-case, латиницей, по образцу `"acolyte"`), `title` (по-русски),
   `skillProficiencies` (ровно 2, как у Послушника — баланс с остальной системой), `equipment`
   (список стартового снаряжения, 3-6 предметов), `gold` (в разумных пределах существующего
   Послушника — 10-25 зм, не выбиваться в 0 или в сотни), `feature` (1-2 предложения, оригинальный
   эффект).
3. Ничего не менять в `CharacterWizard.tsx`/UI — массив `BACKGROUNDS` уже отрисовывается как есть.

## DoD

- `BACKGROUNDS` содержит Послушника (не тронут) + все архетипы из оглавления книги, каждый —
  полностью заполненный `BackgroundData` с оригинальными (не позаимствованными из PDF) данными
  владений/снаряжения/золота/особенности.
- Файл PDF не закоммичен, `.gitignore`-правило `/*.pdf` не тронуто (`git status` перед коммитом не
  показывает PDF).
- `$GATES_CMD` зелёный целиком.

## Критерии приёмки

- Реальный сценарий: открыть мастера персонажа, дойти до шага «Предыстория» — видно карточки всех
  новых архетипов рядом с Послушником, выбор любого из них доводит персонажа до «Итога» и создаёт
  его с владениями/снаряжением/золотом выбранной предыстории.

## Критерии тестирования

- Тест, что `BACKGROUNDS.length` равен ожидаемому числу (Послушник + добавленные).
- Тест в `CharacterWizard.test.tsx`: выбрать одну из новых предысторий, дойти до «Итога», создать
  персонажа — владения/снаряжение/золото выбранной предыстории попадают в готового персонажа (по
  образцу существующих тестов на Послушника/custom background).
