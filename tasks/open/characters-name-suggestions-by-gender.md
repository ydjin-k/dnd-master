# characters-name-suggestions-by-gender

Размер: M

## Что нужно

Баг, найденный владельцем на живой сборке: на шаге «Итог» мастера персонажа кнопка «🎲 Предложить
имя» (`src/ui/CharacterWizard.tsx`, `suggestName()`, строки ~252-258) выбирает имя только по расе
(`NAME_SUGGESTIONS[raceId]`) и полностью игнорирует выбранный пол (`gender`, GENDERS =
["Мужской", "Женский"]) — переключение пола ничего не меняет в предлагаемых именах.

`NAME_SUGGESTIONS` (`src/ui/characterCreationData.ts`, ~строка 793) сейчас — плоский
`Record<string, string[]>` по 8 имён на расу (10 рас + `general`), имена в списке смешаны по полу
без разметки.

Правки:

- Переструктурировать `NAME_SUGGESTIONS` так, чтобы у каждой расы (все 10: human, dwarf, halfling,
  elf, gnome, dragonborn, half-orc, half-elf, tiefling) и у `general` было раздельно **20 мужских и
  20 женских** имён — например `Record<string, { male: string[]; female: string[] }>`. Имена —
  такие же придуманные fantasy-звучащие (см. комментарий над константой: SRD не даёт примеров имён,
  это не выдаётся за официальный контент, не берутся имена персонажей книг/игр) — правило и стиль
  каждой расы сохранить, просто расширить каждый существующий список с 8 до 20 на пол.
- `suggestName()` берёт список для текущей пары (раса, пол) — `NAME_SUGGESTIONS[raceId]?.[genderKey]`
  с фолбэком на `NAME_SUGGESTIONS.general[genderKey]`, где `genderKey` — производная от `gender`
  ("Мужской" → male, "Женский" → female).
- Сохранить существующее поведение реролла: «никогда не повторяет последний предложенный вариант,
  если в списке > 1 имени» (`lastSuggestedName`) — логика не завязана на структуру списка, просто
  применяется к выбранному под-списку.
- Ничего не менять в самом переключателе пола — просто выбор пола должен ВЛИЯТЬ на следующую выдачу
  кнопки «Предложить имя», а не что-то генерироваться автоматически при переключении.

## DoD

- `NAME_SUGGESTIONS` — 11 ключей (10 рас + `general`) × 2 пола × 20 имён = 440 имён, без дублей
  внутри одного под-списка.
- `suggestName()` учитывает `gender` из состояния мастера.
- `$GATES_CMD` (`npm run gate`) зелёный целиком.

## Критерии приёмки

- Реальный сценарий: на шаге «Итог» выбрать расу «Дварф», пол «Мужской», несколько раз нажать
  «Предложить имя» — все предложения из мужского списка дварфов. Переключить пол на «Женский», снова
  нажать — предложения сразу пошли из женского списка той же расы, ни одно имя не повторяет то, что
  было в мужском списке как «то же самое имя для другого пола» (списки не пересекаются по замыслу,
  но дублирование конкретного имени в обоих списках не является ошибкой, если оно туда осмысленно
  попало — просто списки должны быть содержательно разными, а не одним и тем же массивом на оба
  пола).

## Критерии тестирования

- Тест в `src/ui/CharacterWizard.test.tsx`: выбрать расу, пол «Мужской», нажать «Предложить имя» —
  результат входит в мужской список этой расы; переключить на «Женский», нажать снова — результат
  входит в женский список.
- Тест, что мужской и женский список одной расы не идентичны (регрессия текущего бага).
