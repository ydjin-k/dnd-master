# characters-custom-background-equipment-expansion

Размер: S

## Контекст

Владелец продукта хочет расширить блок «Своя предыстория» в мастере персонажа
(`CharacterWizard.tsx`):

1. Лимит числа добавляемых предметов снаряжения — сейчас `CUSTOM_BACKGROUND_EQUIPMENT_LIMIT = 5`
   (`characterCreationData.ts` ~716) — увеличить до **7**.
2. Выбор предмета для добавления — сейчас `<select>` (~строка 910-916) предлагает только
   `ADVENTURING_GEAR` («снаряжение авантюриста»). Владелец хочет **полный каталог** — то же самое
   расширение, что уже сделано для инвентаря персонажа в `characters-item-catalog-picker`
   (карточка персонажа, `CharactersPage.tsx`), только здесь применить к этому `<select>` в мастере.

Уже существует `ARMOR: GearData[]` и `ALL_ITEM_NAMES: string[]` (объединённый список **имён**,
без цены/веса) в `characterCreationData.ts` — но этот `<select>` показывает не только имя, а
`{g.name} ({g.cost}, {g.weight})`, значит нужен объединённый список полных объектов
`{name, cost, weight}`, не только имён.

## Что нужно

1. В `characterCreationData.ts`: изменить `CUSTOM_BACKGROUND_EQUIPMENT_LIMIT` с `5` на `7`.
2. В `characterCreationData.ts`: добавить объединённый список объектов вида `{name, cost, weight}`
   из `WEAPONS`, `ARMOR`, `ADVENTURING_GEAR`, `INSTRUMENTS`, `ARTISAN_TOOLS`, `DWARF_TOOL_CHOICES`
   (без дублей по `name` — при совпадении имени между списками взять первое вхождение, порядок
   списков в перечислении здесь и определяет приоритет), например
   `export const ALL_ITEMS_WITH_COST: GearData[]` — `WeaponData`/`InstrumentData`/`GearData` все
   содержат `name`/`cost`/`weight`, поэтому проекция `{name, cost, weight}` подходит для всех
   источников.
3. В `CharacterWizard.tsx` (~910-916): заменить источник опций `<select>` с `ADVENTURING_GEAR` на
   новый объединённый список (`ALL_ITEMS_WITH_COST`), сохранив тот же формат опции `{g.name}
   ({g.cost}, {g.weight})`. `gearToAdd` инициализация (~161, `ADVENTURING_GEAR[0]?.name`) —
   поправить на `ALL_ITEMS_WITH_COST[0]?.name`, чтобы дефолт не потерялся.

## DoD

- В блоке «Своя предыстория» можно добавить до 7 предметов (было 5); при 7 добавленных кнопка
  «Добавить» неактивна, счётчик показывает «7/7».
- Выпадающий список для добавления снаряжения своей предыстории показывает предметы из всех
  категорий (оружие, доспехи, снаряжение авантюриста, инструменты, музыкальные инструменты), не
  только «снаряжение авантюриста».
- `$GATES_CMD` зелёный.

## Критерии приёмки

- В мастере персонажа, «Своя предыстория»: добавить 7 разных предметов — счётчик показывает 7/7,
  кнопка «Добавить» становится неактивной, 8-й предмет добавить нельзя.
- Открыть выпадающий список выбора предмета — видны варианты не только из «снаряжения
  авантюриста» (например, оружие вроде «Кинжал» и доспех вроде «Кожаный доспех» тоже присутствуют).

## Критерии тестирования

- Тест в `CharacterWizard.test.tsx`: добавление 7 предметов заполняет лимит, 8-я попытка не
  проходит (кнопка `disabled` или счётчик не растёт); опции `<select>` содержат хотя бы один
  пример не-`ADVENTURING_GEAR` предмета (оружие или доспех).
