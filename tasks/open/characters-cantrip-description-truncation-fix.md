# characters-cantrip-description-truncation-fix

Размер: S

Правит баг из уже смерженной `characters-cantrip-usage-info`. Не зависит от других открытых
карточек, можно дispatch-ить в любое время (в т.ч. параллельно с левелингом/деньгами — трогает
только одну маленькую функцию в `CharactersPage.tsx`, риск конфликта минимален, но если воркер
левелинга/денег в этот момент активно правит этот же файл — на усмотрение: либо подождать, либо
дать разрешиться конфликту при мерже, он тривиальный).

## Контекст

Владелец продукта заметил: краткое описание заговора в карточке персонажа обрывается на «…»
посреди мысли — предложение не закончено. Причина — `truncateDescription` в `CharactersPage.tsx`
(~строка 136-139):

```ts
function truncateDescription(text: string, max = 90): string {
  if (text.length <= max) return text;
  return `${text.slice(0, max).trimEnd()}…`;
}
```

Обрезает ровно по 90-му символу, не глядя на границы предложений/слов — отсюда обрубленная на
полуслове мысль.

## Что нужно

Переписать `truncateDescription` так, чтобы обрезка происходила по границе законченного
предложения: искать последний символ `.`/`!`/`?` в пределах `max` символов и обрезать по нему (без
добавления «…», раз предложение и так закончено). Если в пределах `max` вообще нет конца
предложения (первое предложение само длиннее лимита) — тогда обрезать по границе последнего слова
(не разрывая слово) и добавить «…» как раньше, это честный fallback для длинных первых предложений.

## DoD

- Краткое описание заговора либо заканчивается на полное предложение (без «…»), либо — только если
  первое предложение длиннее лимита — обрезается по слову с «…».
- `$GATES_CMD` зелёный.

## Критерии приёмки

- Открыть карточку персонажа-заклинателя со знанием заговора, у которого длинное описание — текст
  под заговором заканчивается точкой/восклицательным/вопросительным знаком, не оборванным словом.

## Критерии тестирования

- Тест на `truncateDescription` (вынести в отдельную тестируемую функцию, если сейчас она замкнута
  внутри компонента и недоступна для юнит-теста напрямую — например поднять на уровень модуля):
  текст с несколькими предложениями обрезается по концу первого/второго предложения, влезающего в
  лимит, без «…»; текст с одним длинным предложением обрезается по слову с «…».
