# characters-monk-tool-choice

Размер: S

## Что нужно

У Монаха в описании владений (rules.json → `classes-monk`, показывается как голый текст на шаге
выбора класса) — «Владение инструментами: выберите один вид инструмента ремесленника либо
музыкального инструмента». Сейчас это просто текст, без выбора — в отличие от уже реализованных
похожих выборов у других рас/классов (дварфийские инструменты — `chosenDwarfTool` в
`CharacterWizard.tsx`, ~строка 156-201; боевой стиль Бойца; избранный враг/местность Следопыта).

Добавить Монаху такой же по устройству выбор: выпадающий список из ремесленных инструментов
(таблица `equipment-tools` в rules.json — те же «Инструменты ремесленников», что уже используются
для дварфийского выбора) ИЛИ музыкальных инструментов (та же таблица, раздел «Музыкальные
инструменты», уже есть список `BARD_INSTRUMENTS`/аналог для инструмента лютни у Барда — переиспользовать
тот же источник списка инструментов, не заводить второй). Выбор — по образцу дварфа: состояние
`chosenMonkTool`, показывается только когда `classId === "classes-monk"`, итоговое значение
подставляется в текст описания на «Итоге» тем же способом, что у дварфа (`finalDwarfTool` →
переписывание `description` фичи «Владение инструментами»).

## DoD

- На шаге выбора класса для Монаха — выпадающий список: сначала выбор категории (ремесленный
  инструмент / музыкальный инструмент), затем выбор конкретного инструмента из соответствующей
  таблицы SRD.
- Выбор отражается в тексте на «Итоге» (аналогично тому, как это уже сделано для дварфийских
  инструментов).

## Критерии тестирования

- Тест в `CharacterWizard.test.tsx`: выбрать Монаха, выбрать конкретный инструмент — текст на «Итоге»
  содержит выбранное название (по образцу существующего теста на дварфийский выбор инструментов).
