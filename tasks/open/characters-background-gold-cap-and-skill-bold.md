# characters-background-gold-cap-and-skill-bold

Размер: S

## Что нужно — два независимых мелких пункта, оба в `CharacterWizard.tsx`

**1. Лимит золота у своей предыстории.** На шаге «Предыстория», ветка «своя предыстория»
(`customBackground`), поле «Золото» (~строка 882-894): `<input type="number" min={0} ...>` без
верхней границы — можно ввести сколь угодно большое число (`min` на `<input type="number">` не
блокирует ввод текстом/вставкой, только стрелочки). Владелец продукта: ограничить 30 (зм) —
максимум, который есть у любой из уже существующих предысторий, ни одна не выдаёт больше 25.
Добавить `max={30}` на сам `<input>` (для стрелочек/семантики) И клэмпить значение в обработчике
`onChange` (`Number(raw) || 0` → дополнительно `Math.min(30, ...)`), раз `max` сам по себе не
достаточен для набранного вручную числа.

**2. Навыки предыстории не выделены жирным в превью.** Шаг «Предыстория», превью выбранной
предыстории (~строка 904-913): `<strong>Навыки:</strong> {background.skillProficiencies.join(", ")}`
— жирный только сам ярлык «Навыки:», а не названия навыков после двоеточия. Владелец продукта явно
это заметил и указал поправить. Сделать жирными сами названия навыков — например, обернуть каждый
элемент `skillProficiencies` в собственный `<strong>`, разделяя запятыми обычным текстом (не всю
строку целиком одним `<strong>`, чтобы разделители-запятые не были жирными). Той же строкой ниже —
`<strong>Снаряжение:</strong> {background.equipment.join(", ")}` страдает тем же — раз чиним ровно
этот визуальный баг в ровно этом месте, поправить и названия предметов снаряжения тем же способом
(тот же паттерн `<strong>` на каждый элемент), не оставлять их асимметрично разными.

Это НЕ часть отложенной `ui-typography-overhaul` (декоративный шрифт, общий проход по всему
приложению) — узкий точечный фикс в одном конкретном месте, где владелец явно указал на конкретный
баг.

## DoD

- Поле «Золото» своей предыстории не даёт ввести/сохранить значение больше 30.
- В превью предыстории (шаг «Предыстория») названия навыков и предметов снаряжения — жирным,
  ярлыки «Навыки:»/«Снаряжение:» — как и раньше.

## Критерии тестирования

- Тест: ввести в поле «Золото» своей предыстории число 999 — итоговое значение персонажа не
  превышает 30.
- Тест/визуальная проверка: у выбранной предыстории названия навыков в превью обёрнуты в `<strong>`
  по отдельности.
