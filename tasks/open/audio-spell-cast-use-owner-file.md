# audio-spell-cast-use-owner-file

Размер: XS. Зона: `engine`/аудио, файл `src/audio/uiSounds.ts`. Роль-исполнитель — `developer`.

## Контекст

Владелец продукта протестировал звук сотворения заклинания и он ему не понравился — сейчас
`playSpellCastSound()` (`src/audio/uiSounds.ts` строка 68) синтезирует звук через Web Audio (три
осциллятора), как раньше было с звуками крита на кубиках до того, как владелец подбросил готовые
файлы (`dice-crit-success.mp3`/`dice-crit-fail.mp3`, см. историю проекта — тот же паттерн, тут
повторяется). Владелец **уже загрузил** готовый файл: `public/audio/Звук магии.mp3` (лежит в
репозитории как untracked — сам файл на месте, просто не переименован/не подключён).

## Что нужно

1. Переименовать `public/audio/Звук магии.mp3` → `public/audio/spell-cast.mp3` (ASCII-имя, по
   образцу уже существующих `dice-crit-success.mp3`, `level-up.mp3`, `coins-jingle.mp3` и т.п.).
2. Заменить тело `playSpellCastSound()` на `playAudioFile("/audio/spell-cast.mp3", <громкость>)` —
   тот же паттерн, что уже использует `playLevelUpSound`/`playCoinsSound`/`playCriticalSuccessSound`
   в этом же файле. Подобрать громкость визуально/на слух в живом приложении (ориентир — громкость
   существующих файловых звуков, 0.55-0.65), не оставлять на максимум по умолчанию.
3. Удалить весь код синтеза (три осциллятора/гейн), он больше не нужен.

## DoD

- При сотворении заклинания в бою звучит именно загруженный владельцем файл, не синтезированный
  тон.
- Старый код синтеза удалён, не оставлен закомментированным/мёртвым.
- `$GATES_CMD` зелёный.

## Критерии приёмки

- В живом Tauri-окне сотворить заклинание в бою — звучит файл `spell-cast.mp3`, громкость сравнима
  с другими звуковыми эффектами приложения (не громче/тише на слух).

## Критерии тестирования

- Если есть существующий тест на вызов `playSpellCastSound`/использование Web Audio API для этого
  звука — обновить под новый файловый паттерн (по образцу тестов на `playLevelUpSound` и т.п., если
  такие есть).
