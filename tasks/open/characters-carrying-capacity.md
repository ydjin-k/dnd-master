# characters-carrying-capacity

Размер: M

**Диспатчить ПОСЛЕ `characters-leveling-1-5` И `characters-currency-denominations`** (та карточка,
если обе в очереди — делать currency первой: у неё структура монет, чей вес тоже входит в общий
переносимый вес по SRD, эта карточка должна её переиспользовать, не задваивать). Пересекается по
файлам с обеими.

## Контекст

Владелец продукта хочет, чтобы приложение считало вес снаряжения персонажа относительно того,
сколько персонаж может нести, и сообщало о перегрузке.

Точное правило — **сверено по `rules.json → gameplay-abilities`** (уже прочитано в этой сессии, не
перепроверять), дословно: «Ваша грузоподъёмность это ваше значение Силы, умноженное на 15. Такой
вес (в фунтах) вы можете носить». Это базовое (не «расширенное»/вариативное) правило — использовать
именно его, не более сложный опциональный вариант с несколькими порогами «слегка/сильно нагружен»
(SRD сам называет тот вариант необязательным усложнением — если владелец продукта попросит более
детальную версию позже, это будет отдельная карточка).

**Пробел в данных, который эта карточка должна закрыть**: у `InventoryItem` (`model.rs`/`types.ts`)
сейчас нет поля веса вообще — только `name`/`quantity`/`notes`. У предметов из общего каталога
(`ALL_ITEMS_WITH_COST`/`WEAPONS`/`ARMOR`/`ADVENTURING_GEAR`/`INSTRUMENTS`/`ARTISAN_TOOLS`/
`DWARF_TOOL_CHOICES`) вес уже есть как строка вида «10 фнт.» — нужно распарсить в число.

## Что нужно

1. **`InventoryItem` получает поле `weightLb: f64`** (TS + Rust, default 0.0). При добавлении
   предмета из подсказок каталога (`ALL_ITEMS_WITH_COST`, уже используется в `datalist` инвентаря) —
   найти совпадение по имени и подставить его вес (распарсить строку веса вроде «10 фнт.» в число —
   например регэксп на первое число в строке; строки вида «—» или без числа → 0). Для полностью
   произвольного (не из каталога) названия — вес остаётся 0 (честное текущее ограничение, не
   пытаться угадать вес выдуманного предмета).
2. **Расчёт общего веса**: сумма `item.weightLb × item.quantity` по всему инвентарю **плюс вес
   монет** — по правилу из `characters-currency-denominations` (50 монет любого номинала = 1 фунт,
   то есть общее число монет всех номиналов, делённое на 50).
3. **Грузоподъёмность** = `abilities.strength × 15` (фунтов).
4. **В карточке персонажа** — строка вида «Вес: 42 / 225 фнт.» рядом с уже существующими
   HP/КД/скоростью и т.п. Когда общий вес превышает грузоподъёмность — явное визуальное
   предупреждение (например красный текст/иконка, класс вроде уже существующего
   `character-card__danger`, если такой паттерн уже есть в CSS проекта — проверить и переиспользовать
   стиль, не изобретать новый) с текстом вроде «Перегрузка!».

## DoD

- Каждый предмет из каталога, добавленный в инвентарь, несёт свой вес; общий вес персонажа виден в
  карточке рядом с грузоподъёмностью (Сила × 15).
- При превышении — явное предупреждение о перегрузке.
- Монеты корректно учитываются в общем весе (по курсу 50 монет/фунт).
- `$GATES_CMD` зелёный.

## Критерии приёмки

- Персонаж с Силой 10 (грузоподъёмность 150 фнт.) — добавить снаряжение суммарным весом больше
  150 фнт. — видно предупреждение о перегрузке. Убрать часть снаряжения, вес падает ниже порога —
  предупреждение исчезает.
- Добавить 100 медных монет (по курсу — 2 фунта) — общий вес персонажа увеличивается на 2 фунта.

## Критерии тестирования

- Тест на подсчёт общего веса: известный набор предметов из каталога + известное число монет даёт
  ожидаемую сумму.
- Тест, что предупреждение о перегрузке появляется/исчезает при переходе через порог
  `strength × 15`.
