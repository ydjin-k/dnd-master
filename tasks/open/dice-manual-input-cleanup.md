# dice-manual-input-cleanup

Размер: XS. Зона: `engine` (кубики). Роль-исполнитель — `developer` (см. `gamestudio/roles/developer.md`
и `roles/_common.md`).

## Контекст

Владелец продукта протестировал повторно после фикса наложения раскрывающегося селектора
(`journal-book-spread-and-dice-overlap-fix`) и уточнил, что имел в виду другую проблему на том же
поле: `src/ui/pages/DicePage.tsx`, форма `.dice-page__manual` — поле `<input type="number">` для
результата ручного броска. «Селектор» в жалобе — это **нативный спиннер (стрелки
увеличить/уменьшить) браузерного `<input type="number">`**, который в узком поле (`width: 5ch`)
занимает заметную часть той самой ячейки, куда нужно вписать число. Владелец прямо попросил: убрать
этот селектор полностью, оставить только пустое поле ввода и кнопку, сохраняющую результат по клику
(кнопка «Записать вручную» уже это делает, `recordManual` — не трогать логику).

Отдельно: в логе бросков запись ручного результата подписана словом с маленькой буквы
(`label: "вручную"` в `recordManual`) — поправить на «Вручную».

## Что нужно

1. Убрать нативный спиннер у `.dice-page__manual input` — оставить обычное поле для ввода числа без
   видимых стрелок увеличения/уменьшения. Самый надёжный способ в Chromium/WebView2 — CSS:
   ```css
   .dice-page__manual input::-webkit-outer-spin-button,
   .dice-page__manual input::-webkit-inner-spin-button {
     -webkit-appearance: none;
     margin: 0;
   }
   .dice-page__manual input[type="number"] {
     -moz-appearance: textfield;
   }
   ```
   Если по факту в живом приложении спиннер всё равно виден (сверить визуально в запущенном
   Tauri-окне, не только в теории) — как альтернативу можно сменить `type="number"` на
   `type="text" inputmode="numeric" pattern="-?[0-9]*"` (валидация уже мягкая — `Number(manualValue)`
   в `recordManual` и так проверяет `Number.isFinite`, отрицательные и пустые значения корректно
   отбрасываются или обрабатываются как сейчас). Главное — визуально в поле не должно быть ничего,
   кроме места под цифры.
2. В `recordManual` заменить `label: "вручную"` на `label: "Вручную"`.

## DoD

- Поле ручного ввода на «Кубиках» не показывает никаких стрелок/спиннера — только текстовый ввод.
- Кнопка «Записать вручную» по-прежнему сохраняет введённое число в лог (поведение не менялось).
- Запись в логе после ручного ввода подписана «Вручную» (с большой буквы).
- `$GATES_CMD` зелёный.

## Критерии приёмки

- Открыть «Кубики», навести/кликнуть в поле ручного ввода — никакого спиннера не видно, только
  курсор для ввода цифр.
- Ввести число, нажать «Записать вручную» — в логе строка со словом «Вручную» (не «вручную»).

## Критерии тестирования

- Существующие тесты `DicePage.test.tsx` на ручной ввод остаются зелёными; если там есть проверка
  текста лога — поправить ожидаемую строку на «Вручную».
