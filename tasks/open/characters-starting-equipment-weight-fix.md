# characters-starting-equipment-weight-fix

Размер: S

## Контекст

Баг, найденный владельцем продукта: предметы стартового снаряжения (те, что добавляются в
инвентарь автоматически по классу/предыстории на этапе создания персонажа в `CharacterWizard.tsx`)
получают `weightLb: 0` по умолчанию — значит увеличение их количества кнопкой «+» в карточке
персонажа не увеличивает общий вес, хотя должно (эти предметы почти всегда есть в каталоге
`ALL_ITEMS_WITH_COST` с известным весом).

Причина: авто-подстановка веса по имени (`catalogWeightLb`, добавлена в
`characters-carrying-capacity`) сейчас вызывается только в ручном добавлении предмета через поле
«Новый предмет» в `CharactersPage.tsx` — там, где `CharacterWizard.tsx` формирует стартовый
инвентарь персонажа (класс/предыстория дают конкретные предметы), эта функция не вызывается вообще.

## Что нужно

Найти в `CharacterWizard.tsx` место(а), где формируется массив `inventory: InventoryItem[]` для
нового персонажа (стартовое снаряжение класса + предыстории), и для каждого предмета подставлять
`weightLb: catalogWeightLb(name)` вместо оставления поля нулевым/неопределённым — тем же вызовом,
что уже используется в `CharactersPage.tsx`. Владелец продукта явно просит: «исключений нет
никаких» — каждый предмет, попадающий в инвентарь любым путём (мастер или ручное добавление),
должен иметь подставленный вес, если он есть в каталоге.

## DoD

- Персонаж, созданный через мастер, имеет реальный вес у каждого предмета стартового снаряжения,
  найденного в каталоге (не 0), и увеличение количества такого предмета в карточке реально
  увеличивает общий переносимый вес.
- `$GATES_CMD` зелёный.

## Критерии приёмки

- Создать персонажа-Воина через мастер (стартовое снаряжение включает доспех/оружие) — открыть
  карточку, посмотреть общий вес: он больше 0 сразу после создания (не только после ручного
  добавления предметов). Нажать «+» на любом стартовом предмете — общий вес увеличивается.

## Критерии тестирования

- Тест в `CharacterWizard.test.tsx`: созданный персонаж имеет ненулевой `weightLb` хотя бы у одного
  предмета стартового снаряжения, известного каталогу.
