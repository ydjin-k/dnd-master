# characters-skill-ability-modifiers

Размер: M

Зависимости: строится поверх `characters-skill-proficiency-bonus-hint` (уже смержено) —
`PROFICIENCY_BONUS_HINT`/`PROFICIENCY_BONUS_LEVEL_1` уже существуют в `characterCreationData.ts`.
Этот текст-объяснение **остаётся**, просто рядом с ним теперь появляется число.

## Контекст

Владелец продукта хочет видеть у каждого навыка не только текстовое объяснение про бонус
мастерства, но и итоговое **число** — модификатор характеристики + (бонус мастерства, если есть
владение) — и на шаге «Итог» мастера персонажа, и в уже созданной карточке персонажа
(`CharactersPage.tsx`).

Сейчас в приложении **нет** сопоставления «навык → характеристика» как данных — оно нужно для
расчёта. Стандартное сопоставление SRD 5.1 (сверить каждую пару с текстом описания навыка в
`rules.json`, например у «Акробатика» дословно написано «Ваша проверка **ловкости** (акробатики)»
— искать такую формулировку «проверка X (навык)» для каждого из 18 навыков в `ALL_SKILLS`, не
полагаться на память о D&D):
Акробатика→Ловкость, Обращение с животными→Мудрость, Атлетика→Сила, Обман→Харизма,
История→Интеллект, Проницательность→Мудрость, Запугивание→Харизма, Расследование→Интеллект,
Медицина→Мудрость, Магия→Интеллект, Природа→Интеллект, Восприятие→Мудрость,
Выступление→Харизма, Убеждение→Харизма, Религия→Интеллект, Ловкость рук→Ловкость,
Скрытность→Ловкость, Выживание→Мудрость. **Сверить каждую пару с `rules.json` перед тем, как
зашивать в код** — список выше для ориентира, не для слепого копирования.

Модификатор характеристики уже считается: `abilityMod()` в `CharacterWizard.tsx`. Спасброски уже
знают свою характеристику через `savingThrowLabels`/`CLASS_PROFICIENCIES` — для них число также
нужно.

## Что нужно

1. В `characterCreationData.ts`: добавить `SKILL_ABILITY: Record<string, AbilityKey>` — 18 навыков
   → соответствующая характеристика, сверенная по `rules.json` как описано выше.
2. На шаге «Итог» (`CharacterWizard.tsx` ~1239-1247) и в карточке персонажа (`CharactersPage.tsx`
   ~120-127) — рядом с каждым навыком и каждым спасброском показать посчитанное число: модификатор
   характеристики персонажа + (`PROFICIENCY_BONUS_LEVEL_1`, если персонаж владеет этим навыком/
   спасброском, иначе 0), в привычном виде со знаком (например «+4», «−1»). Список навыков сейчас
   рендерится как один `.join(", ")` — потребуется отрендерить каждый навык отдельным элементом
   (`<li>`/`<span>`), чтобы у каждого было своё число.
3. Текст `PROFICIENCY_BONUS_HINT` **не убирать** — он остаётся как объяснение того, что означает
   число у навыков-владений (по прямой просьбе владельца продукта: «пояснение про владение никуда
   не девается»).
4. Модификатор характеристики без владения (обычная проверка навыком, которым персонаж не владеет)
   тоже нужен — не только у навыков-владений: показать число у ВСЕХ навыков персонажа (не только
   тех, которыми он владеет), чтобы это было полноценной шпаргалкой, как просил владелец продукта
   («какие характеристики к каким навыкам относятся, и соответственно уже прибавлять модификатор и
   бонус мастерства»).

## DoD

- Каждый из 18 навыков на шаге «Итог» и в карточке персонажа показывает готовое число (модификатор
  характеристики + бонус мастерства при владении), не только текст.
- Спасброски показывают то же самое.
- Текст-объяснение про бонус мастерства остаётся видимым.
- `$GATES_CMD` зелёный.

## Критерии приёмки

- Создать персонажа с известными характеристиками и владением конкретным навыком — число рядом с
  этим навыком равно модификатору соответствующей характеристики + 2; у навыка без владения — просто
  модификатор характеристики.

## Критерии тестирования

- Тест на 1-2 конкретных навыка: посчитанное число совпадает с ожидаемым при известных
  характеристиках персонажа.
