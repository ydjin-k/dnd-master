# characters-name-suggestions

Размер: S

## Что нужно

На шаге "Итог" мастера персонажа (`src/ui/CharacterWizard.tsx`), рядом с полем ввода имени —
ненавязчивая кнопка вида "🎲 Предложить имя". По клику подставляет в поле имени случайное имя из
списка, подобранного под выбранную расу (`raceId`); если раса ещё не выбрана — берёт из общего
нейтрального списка. Поле имени остаётся полностью свободным для ручного ввода — кнопка не
заменяет печать, а только предлагает готовый вариант, который можно тут же стереть/поправить.
Повторный клик — новое случайное имя (реролл), не то же самое два раза подряд, если в списке больше
одного варианта.

**Важная оговорка по данным:** в открытом SRD 5.1 (`rules.json`) списков примеров имён по расам
НЕТ — это раздел только в платной Книге игрока. Значит имена в списке — не выверенные по SRD,
а придуманные (fantasy-звучащие, в стиле расы), это нормально: это не игровой контент/правило,
не вопрос авторских прав, просто вкусовая деталь. Не выдавай список за "официальный" ни в
комментариях, ни в UI-тексте.

## DoD

- Список имён по каждой из 9 рас (`characterCreationData.ts`, новая структура вроде
  `NAME_SUGGESTIONS: Record<string, string[]>`) — минимум 6-8 имён на расу, свои, не переведённые
  ниоткуда конкретно.
- Кнопка на шаге "Итог", рядом с полем имени; не обязательна к использованию.
- Реролл при повторном клике не повторяет последний результат (если в списке > 1 варианта).

## Критерии приёмки

- Реальный сценарий: выбрать расу "Дварф", дойти до "Итога", нажать кнопку — в поле имени
  появляется имя из дварфийского списка (не общего/не другой расы). Нажать ещё раз — другое имя.
  Стереть и напечатать своё — работает как обычное поле, ничего не мешает.

## Критерии тестирования

- Тест в `src/ui/CharacterWizard.test.tsx` (смонтированный компонент, по образцу существующих):
  выбрать расу, дойти до "Итога", кликнуть кнопку — значение поля имени стало непустым и входит в
  список этой расы; ручной ввод после клика по-прежнему меняет поле.
- `$GATES_CMD` (`npm run gate`) зелёный целиком.
