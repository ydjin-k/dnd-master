# rules-page-spell-circles-2-9

`ui-developer`.

владельца на dispatch.**

## Контекст

Данные всех заклинаний кругов 0-9 уже есть в `spells.json` (314 заклинаний, доведено карточкой
`rules-spells-data-level-6-9`, закрыта). Расширение самого справочника «Правила» до показа
заклинаний 2 круга и выше было **намеренно оставлено за рамками** той карточки — отдельное решение
владельца, до сих пор не оформленное как task-карточка.

Сейчас `RulesPage.tsx` жёстко зашивает только два раздела:
- `cantrips` — `spells.filter(sp.level === 0)` (строка 64)
- `firstLevelSpells` — заговоры круга 1 (строка 65-68)

и рендерит только их в навигации (заголовки «Заговоры» строка ~124-131, «Заклинания 1 уровня»
строка 133-145). Кругов 2-9 в списке нет вообще — не только 2-6.

## Что нужно

- Обобщить фильтрацию по кругу (сейчас два похожих блока `cantrips`/`firstLevelSpells` с почти
  идентичной логикой) на все круги 0-9, например через один список секций
  `[{ level: 0, title: "Заговоры" }, { level: 1, title: "Заклинания 1 круга" }, ..., { level: 9,
  title: "Заклинания 9 круга" }]`, отрендеренных одним циклом, а не 9 копипастами.
  Каждый раздел рендерится только если в нём есть хотя бы одно заклинание, прошедшее поиск (по
  образцу текущего `visibleFirstLevelSpells.length > 0 && (...)`).
- Поиск (`query`) должен продолжать фильтровать по всем кругам одинаково, не только по 0-1.
- `SpellView`/отображение самого заклинания при клике — не трогать, оно уже общее для любого
  заклинания независимо от круга.

## DoD

- В справочнике «Правила» видны разделы для каждого круга 0-9, у которого есть хотя бы одно
  заклинание в `spells.json`.
- Поиск фильтрует заклинания любого круга, не только заговоры и 1 круг.
- `$GATES_CMD` зелёный.

## Критерии приёмки

- Открыть вкладку «Правила» — в навигации видны разделы вплоть до «Заклинания 9 круга» (или
  максимального круга, где есть данные), клик по заклинанию высокого круга показывает его текст.
- Ввести в поиск название заклинания 6+ круга — оно находится и показывается.

## Критерии тестирования

- Тест, что заклинание 5+ круга рендерится в навигации и открывается по клику (сейчас такого теста
  нет — только на заговоры/1 круг).
- Тест, что поиск находит заклинание любого круга, не только 0-1.
