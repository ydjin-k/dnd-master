# ui-shell-adventures-generator-narrow-table-label

Зона: `ui-shell` (вкладка «Приключения», генератор событий).  
Размер: **S**. Роль: QA / Tester.

## Экран и размер

Экран «Генератор событий», окно **620×700**, выбран стол «Подземье: проверка столкновения
(d20)».

## Шаги

1. Открыть «Приключения» → «Сгенерировать события».
2. Выбрать «Подземье: проверка столкновения (d20)».

## Что видно

В закрытом поле «Таблица» длинное выбранное имя обрезается у правой границы: отображается только
начало строки (`Подземье: проверка столкновения (d...`), без многоточия и другого признака, что
текст не помещается. Значение остаётся допустимым в списке, но в закрытом состоянии выбранную
таблицу нельзя прочитать целиком.

Доказательство: `docs/qa/evidence/qa-2026-10-18-adventures-narrow-table-label.png`.

## Как должно быть

Выбранное значение читается целиком либо обрезается с видимым многоточием; допустимы перенос,
адаптивная ширина или подсказка с полным названием.
