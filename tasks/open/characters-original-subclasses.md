# characters-original-subclasses

Размер: XL — большая многосессионная задача (12 классов × 2 новых архетипа каждый = 24 новых трека
особенностей по уровням 1-5). Коммитить инкрементально по классам, в отчёте явно указать, сколько
классов реально доделано.

## Контекст

Владелец продукта потестировал левелинг и заметил, что у каждого класса сейчас только один
архетип/подкласс на выбор — спросил, не должно ли быть больше (в его памяти по игре — да).

**Это не баг, а точная граница открытой лицензии**: SRD 5.1 (на которой строится всё приложение)
официально содержит **ровно один архетип на класс** — то, что уже реализовано в
`CLASS_SUBCLASSES` (Бард → «Коллегия знаний», Воин → «Воитель», Волшебник → «Школа эвокации» и
т.д., по одному на все 12 классов). Личная PHB владельца продукта (уже фигурировавшая в этом
проекте раньше, см. `srd-only-content-boundary`) содержит по 2-4 архетипа на класс, но **копировать
её текст/механики нельзя** — та же граница, что и с предысториями (`characters-backgrounds-full`):
PHB можно использовать только чтобы **подтвердить, какие архетипы вообще существуют** (имена/общая
тема), но конкретные особенности по уровням — писать 100% оригинальными, вдохновляясь только общей
темой архетипа (жанровым тропом), не копируя книжную комбинацию способностей/чисел.

**Владелец продукта подтвердил этот подход явно** («добавить оригинальные»).

## Что нужно

Добавить **по 2 новых оригинальных архетипа на каждый из 12 классов** (итого 3 варианта на класс,
считая уже существующий SRD-архетип). Ориентир по именам — из PHB (только чтобы понять, какая тема
уже существует и не изобретать то, что не будет ощущаться «родным» для класса), но **не копировать
их конкретные способности**:

| Класс | Уже есть (SRD) | Добавить (только тема/имя, механики — оригинальные) |
|---|---|---|
| Бард | Коллегия знаний | ~Коллегия доблести (боевой), ~Коллегия шёпота/теней (плутовской) |
| Варвар | Путь Берсерка | ~Путь Тотемного воина (звериная тема), ~Путь Штурмовика/буйства |
| Воин | Воитель | ~Мастер боя (тактика/манёвры), ~Мистический рыцарь (магия+меч) |
| Волшебник | Школа эвокации | ~Школа воплощения/иллюзий, ~Школа некромантии |
| Друид | Круг земли | ~Круг луны (звериный облик, боевой), ~Круг звёзд/снов |
| Жрец | Домен жизни | ~Домен войны, ~Домен обмана/природы |
| Колдун | Потусторонний покровитель | ~Покровитель-Архифея, ~Покровитель-Древний Ужас |
| Монах | Монастырская традиция | ~Путь открытой ладони, ~Путь тени |
| Паладин | Священная клятва | ~Клятва древних, ~Клятва мести |
| Плут | Архетип плута | ~Убийца, ~Мистический ловкач (немного магии) |
| Следопыт | Архетип следопыта | ~Укротитель зверей (спутник-животное), ~Странник |
| Чародей | Происхождение чародея | ~Дикая магия, ~Происхождение от бури/стихий |

Для каждого нового архетипа: имя, краткое тематическое описание (2-3 предложения, оригинальный
текст), и особенности по уровням 1-5 в том же формате, что у уже существующих SRD-архетипов
(`featuresByLevel` в `CLASS_SUBCLASSES`) — держать примерно тот же уровень мощи/детализации, что у
существующего SRD-архетипа того же класса (не сильнее и не слабее), чтобы игровой баланс не
перекашивало.

**Важное дополнение — сейчас выбор архетипа вообще не UI, а автоподстановка первого варианта**
(`subclassInfo.subclasses[0]`, и в `CharacterWizard.tsx`, и в левел-апе `CharactersPage.tsx`) — это
было нормально при единственном варианте, но при трёх вариантах так оставлять нельзя. Добавить
реальный выбор (выпадающий список с именем + кратким описанием) везде, где сейчас подкласс
назначается автоматически:
- В мастере персонажа, на шаге «Итог» — для Жреца/Колдуна/Чародея (архетип на 1 уровне).
- В левел-апе — для остальных 9 классов (архетип на 2 или 3 уровне, всплывает как и ASI-панель на
  4 уровне — похожий паттерн выбора перед подтверждением левел-апа).

## DoD

- Каждый класс предлагает 3 архетипа на выбор (1 SRD + 2 оригинальных), с полноценными
  особенностями по уровням 1-5.
- Выбор архетипа — реальный UI-контрол (не автоподстановка), везде, где раньше был единственный
  вариант.
- `$GATES_CMD` зелёный на каждом инкрементальном коммите.

## Критерии приёмки

- Создать персонажа-Жреца — на «Итоге» мастера предлагается выбрать один из 3 доменов, каждый с
  осмысленным оригинальным текстом особенности 1 уровня.
- Создать персонажа-Воина, повысить до 3 уровня — левел-ап предлагает выбрать один из 3 воинских
  архетипов, а не назначает автоматически.

## Критерии тестирования

- Тест, что `CLASS_SUBCLASSES` содержит ровно 3 варианта для каждого из 12 классов.
- Тест, что UI выбора архетипа рендерит все варианты и сохраняет именно выбранный (не всегда
  первый).
