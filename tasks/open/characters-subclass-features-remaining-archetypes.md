# characters-subclass-features-remaining-archetypes

Размер: XL (28 архетипов из 10 классов — почти в 4 раза больше, чем уже сделано в
`characters-subclass-features-have-no-mechanical-effect` (8 архетипов, см. запись 70 в `tasks/DONE.md`) —
скорее всего не влезет в одну сессию воркера целиком, см. «Как поступить, если не успеваешь» ниже).

## Контекст

Прошлая карточка дала реальный механический эффект 8 из 36 архетипов (домены Жреца ×3, клятвы Паладина ×3,
Коллегия доблести Барда, Наследие драконьей крови Чародея) — см. `CLASS_SUBCLASSES` в
`src/ui/characterCreationData.ts`, у них есть поле `grants`. Владелец продукта хочет распространить тот же
паттерн на оставшиеся **28 архетипов** (у них есть только `featuresByLevel` — текст без эффекта):

- Колдун (`classes-warlock`): Исчадие, Покровитель-Архифея, Покровитель-Древний Ужас (3)
- Чародей (`classes-sorcerer`): Дикая магия, Происхождение от бури (2 — Наследие драконьей крови уже сделано)
- Волшебник (`classes-wizard`): Школа эвокации, Школа иллюзий, Школа некромантии (3)
- Друид (`classes-druid`): Круг земли, Круг луны, Круг звёзд (3)
- Бард (`classes-bard`): Коллегия знаний, Коллегия шёпота (2 — Коллегия доблести уже сделана)
- Варвар (`classes-barbarian`): Путь Берсерка, Путь Тотемного воина, Путь Штурмовика (3)
- Воин (`classes-fighter`): Воитель, Мастер боя, Мистический рыцарь (3)
- Монах (`classes-monk`): Путь открытой ладони, Путь тени, Путь четырёх стихий (3)
- Плут (`classes-rogue`): Вор, Убийца, Мистический ловкач (3)
- Следопыт (`classes-ranger`): Охотник, Укротитель зверей, Странник (3)

**Не изобретать новую систему** — расширять именно `grants` (`armor`, `weaponCategories`, `skills`,
`resourceOptions`, `spellsByLevel`, `healingBonus`, `unarmoredAc`) и то, что уже читает эти поля:
`withRecomputedArmorClass`/`applySubclassOption`/`subclassSpellsUpToLevel` и т.п. в `CharactersPage.tsx` /
`characterCreationData.ts`. Часть архетипов не подходит ни под один из существующих `grants`-ключей
(например, «раз за длинный отдых бонусное действие», «перебросить кубик атаки») — если существующих
структур не хватает, добавлять новый узкий ключ по тому же паттерну, а не текстовую заглушку.

**Важная находка прошлого воркера, не игнорировать:** SRD-текст двух архетипов ссылается на владение
инструментами (Коллегия шёпота — воровские инструменты для подделки; Убийца — инструменты для маскировки),
а в модели персонажа **поля владения инструментами нет вообще** (есть только `armorProficiencies`/
`weaponProficiencies`). Прежде чем эти два архетипа получат `grants`, нужно решить: заводить ли новое поле
`toolProficiencies: string[]` в модели (аналогично оружию/доспехам) — если решать это на месте молча,
проверить с владельцем продукта уместность или явно задать вопрос по ходу задачи, не выдумывать
несуществующее правило.

## Что нужно

1. Для каждого из 28 архетипов — реальный `grants` по образцу уже сделанных 8: владения (доспехи/оружие/
   навыки), рабочий ресурс с кнопкой (по образцу Проведения энергии — `resourceOptions`), заклинания школы/
   покровителя/круга/происхождения там, где SRD их называет явно.
2. Там, где эффект не укладывается в существующие `grants`-ключи (например, «дикий всплеск» Чародея,
   «звериный спутник» Следопыта, «боевое превосходство» Мастера боя, «Дикий облик бонусным действием»
   Круга луны) — расширить типы `grants`/`ClassSubclassInfo` узким новым полем и подключить его в UI, не
   оставлять текстом-обещанием.
3. Не трогать 8 уже готовых архетипов и общий движок (`withRecomputedArmorClass`, расчёт КД) без нужды —
   расширять, а не переписывать.

## Как поступить, если не успеваешь за одну сессию

28 архетипов с реальными эффектами — большой объём. Коммитить инкрементально по мере готовности каждого
класса (а не одним финальным коммитом), в конце отчёта явно указать: какие архетипы получили `grants`, какие
остались (поимённо) — чтобы можно было отправить карточку-продолжение точно на оставшееся.

## DoD

- Хотя бы часть из 28 архетипов реально получила `grants` (отчёт явно называет, сколько и какие).
- Уже готовые 8 архетипов и весь текущий функционал (КД, инвентарь, левел-ап) продолжают работать без
  регрессий.
- `$GATES_CMD` зелёный **и отдельно `cargo test`** зелёный (гейты не гоняют `cargo test`, см. память
  проекта — обязательно прогнать вручную, если тронут Rust).

## Критерии приёмки

- Персонаж с одним из новых архетипов на нужном уровне видит эффект не только текстом: доступный ресурс с
  кнопкой применения (если архетип его даёт), владения в разделе «Оружие и доспехи», заклинания архетипа в
  списке известных (если применимо).

## Критерии тестирования

- Для каждого добавленного `grants` — как минимум одна положительная проба (эффект есть) и одна
  отрицательная (без архетипа/гранта эффекта нет), по образцу уже существующих проб для 8 готовых архетипов.
