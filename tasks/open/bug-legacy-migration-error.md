# bug-legacy-migration-error

Размер: S

## Что не так

`migrate_legacy_if_needed` в `src-tauri/src/storage.rs` читает старый `campaign.json` так:

```rust
let mut state = read_campaign_file(&legacy_path).unwrap_or_default();
```

Если файл повреждён или не парсится — вместо ошибки тихо подставляется пустая кампания (без
персонажей), и файл всё равно переименовывается в `campaign.json.migrated`, как будто миграция
прошла успешно. Игрок в этом случае видит новую пустую кампанию и не получает никакого сигнала,
что со старым сохранением что-то не так.

Найдено внешним ревью (Codex, второе мнение по коду), проверено вручную — воспроизводится чтением
кода один в один.

## DoD

- `migrate_legacy_if_needed` (или вызывающий её `load_active_in`/`list_campaigns_in`) возвращает
  `Err` с понятным текстом, если `campaign.json` существует, но не парсится — а не тихую пустую
  кампанию.
- Оригинальный `campaign.json` не переименовывается/не трогается, пока миграция не прошла успешно
  (переименование в `.migrated` — это подтверждение успеха, не действие "в любом случае").
- Существующие сценарии (валидный legacy-файл мигрирует как раньше, отсутствие legacy-файла —
  no-op) не сломаны.

## Критерии приёмки

- Реальный сценарий: положить в тестовый `base_dir` файл `campaign.json` с невалидным JSON (или
  валидным JSON, но не подходящим под `CampaignState`) — загрузка активной кампании должна вернуть
  `Err`, а не `Ok(пустая кампания)`.
- `campaign.json` в этом сценарии остаётся на месте (не переименован в `.migrated`).

## Критерии тестирования

- Новый тест в `src-tauri/src/storage.rs` (`#[cfg(test)] mod tests`), рядом с существующими
  `legacy_single_campaign_file_migrates_once` и `concurrent_first_launch_migrates_legacy_exactly_once`:
  кладёт заведомо неразбираемый `campaign.json`, ожидает `Err` от `load_active_in`, и проверяет, что
  файл НЕ переименован.
- Отрицательная проба: без починки (текущий `unwrap_or_default()`) этот тест должен падать —
  проверь это перед сдачей (снять починку → тест красный → вернуть).
- `$GATES_CMD` (`npm run gate`) зелёный целиком.
