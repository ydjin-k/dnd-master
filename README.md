# DnD Master

Помощник мастера для настольной ролевой игры Dungeons & Dragons 5e.

Игру ведёт живой Мастер, а приложение берёт на себя рутину: считает, помнит и показывает то, что
обычно держат на бумаге. Решения остаются за Мастером. Работает без интернета, без подписок и
без регистрации.

## Скачать

Установщик для Windows — на странице [Releases](https://github.com/ydjin-k/dnd-master/releases/latest):
файл `DnD-Master_…_x64-setup.exe`.

## Что умеет

- **Персонажи** — создание персонажа с нуля или из готового пресета, лист персонажа с хитами,
  состояниями, инвентарём, деньгами и заклинаниями; портреты в комплекте.
- **Бой** — порядок ходов по инициативе и хиты участников.
- **Кубики** — бросок любых стандартных кубиков или ввод результата живого броска.
- **Приключения** — таблицы случайных событий и встреч, расчёт пути и темпа отряда.
- **Подземелья** — генератор подземелий с комнатами, ловушками и находками, отдельное окно для игроков.
- **Дневник** — журнал событий кампании.
- **Правила, Заклинания, Бестиарий** — справочник по SRD с поиском.
- **Саундборд** — фоновые звуки и музыка для сцен.
- **Кампании** — несколько кампаний, у каждой свои персонажи и записи.

## Правила

Основа правил — открытые правила D&D 5e, System Reference Document 5.1 от Wizards of the Coast,
распространяемый по лицензии [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/legalcode).
Расы и классы сверх SRD — дополнительный материал приложения, в SRD они не входят.
