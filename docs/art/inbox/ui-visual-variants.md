# Варианты визуального направления

Это только предложения для выбора Producer/владельцем продукта. Вёрстка приложения и иконки костей ещё не изменялись.

- `variant-a-ember-forge.svg` — «Кузня углей»: плотная тёмная основа, медные рамки и тёплые акценты. Иконки рубленые и вещественные, меню напоминают кованые панели.
- `variant-b-moonlit-arcana.svg` — «Лунный арканум»: холодная ночная палитра с бирюзовым магическим свечением. Формы мягче, иконки строятся из тонких светящихся линий.
- `variant-c-verdant-grimoire.svg` — «Лесной гримуар»: светлый пергамент, зелёные чернила и ботанические мотивы. Меню выглядят как страницы полевого гримуара, иконки — как печати и гравюры.

Каждый макет содержит палитру, пример выпадающего меню, список подсказок предметов, набор общих иконок и пример d20. После выбора направление следует распространить на все экраны и дорисовать полный набор d4/d6/d8/d10/d12/d20/d100.
