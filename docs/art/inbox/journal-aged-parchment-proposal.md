# Дневник D — «Чернила на старом пергаменте»

Статус: новое предложение после отклонения тёмно-синего гримуара. Production-код Дневника не
изменён; вариант ждёт подтверждения владельца продукта.

Макет: `journal-theme-variant-d-aged-parchment.svg`.

Зона разворота становится состаренной бумагой: тёплая охра в центре, затемнённые и чуть неровные
края, едва заметные волокна и пятна времени. Оболочка приложения остаётся тёмным «Лунным
арканумом», поэтому пергамент читается как физический гримуар, лежащий на ночном столе.

Основной текст — почти чёрные коричневые чернила `#24180f`, служебные пометки — выцветшие чернила
`#59412c`. Caveat уже установлен, поддерживает кириллицу и в размере записей выглядит достаточно
рукописно и каллиграфично; новый шрифт ради одного экрана не предлагается. Для ощущения пера в
выбранной реализации достаточно увеличить вес заголовков записей и добавить лёгкий наклон только
служебным строкам, не искажая длинный текст.

После подтверждения нужно заменить только поверхность разворота и цвета текста/контролов внутри
гримуара. Форма добавления записи может остаться тёмной, связывая пергамент с общей оболочкой.
