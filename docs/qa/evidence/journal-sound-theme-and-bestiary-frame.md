# Проверка рамки бестиария

Дата: 2026-09-02.

Исходные изображения владельца проверены непосредственно в рабочем дереве:

| Существо | Файл | Исходный размер | Старая рамка 320×240: изображение / пустота по бокам | Новая рамка |
|---|---|---:|---:|---:|
| Разбойник | `bandit.png` | 1024×1536 | 160×240 / 160 px | 280×420 |
| Оборотень | `werewolf.jpg` | 794×1000 | 191×240 / 129 px | 320×403 |
| Волк | `wolf.png` | 1122×1402 | 192×240 / 128 px | 320×400 |

До исправления рамка была фиксированным блоком 320×240, а `object-fit: contain` уменьшал портрет
внутри неё, оставляя суммарно 128–160 px пустого пространства по сторонам. После исправления сам
`img` имеет `width: auto; height: auto; max-width: 320px; max-height: 420px`; border расположен на
этом же элементе и потому совпадает с фактическим размером каждого изображения. Обрезания нет.

Снять требуемые PNG-кадры desktop-приложения в этой сессии не удалось: `orca computer capabilities
--json` вернул `runtime_unavailable` (`Could not connect to the running Orca app. Restart Orca and
try again.`). Числа выше получены с реальных файлов владельца, не с заменителей.
